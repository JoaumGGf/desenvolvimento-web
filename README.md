# Descrição do Projeto – Arrays, DOM e Eventos

Este projeto foi desenvolvido em HTML e JavaScript com o objetivo de praticar a manipulação de arrays, elementos do DOM e eventos, criando uma página interativa de gerenciamento de tarefas.

### Métodos de Arrays
- **map():** cria um novo array a partir dos elementos originais, permitindo transformá-los, como converter nomes para letras maiúsculas.
- **filter():** cria um novo array contendo apenas os elementos que atendem a uma condição, como preços maiores que R$ 20.
- **reduce():** percorre os elementos de um array e acumula um resultado, como a soma dos preços dos produtos.
- **forEach():** percorre cada elemento do array para executar uma ação, como imprimir informações ou criar itens de uma lista.

### Manipulação do DOM
A manipulação do DOM permite modificar o conteúdo da página utilizando JavaScript. No projeto, foram utilizados métodos como `querySelector()` para selecionar elementos, `createElement()` para criar novos itens, `append()` para adicioná-los à lista e `classList` para aplicar ou remover estilos.

### Event Delegation
O *Event Delegation* permite controlar os cliques de vários elementos utilizando apenas um `addEventListener()` no elemento pai. Isso melhora a organização do código e pode otimizar a performance, pois evita a criação de vários listeners individuais.

Além disso, permite que elementos adicionados dinamicamente também respondam aos cliques, sem a necessidade de configurar novos eventos para cada item.

### Conclusão
O projeto ajudou a compreender como utilizar JavaScript para manipular dados, modificar páginas HTML e criar interações com o usuário de maneira simples, organizada e eficiente.
